# Simulated reads analysis (Figures 2b and 2c)

Analyses where decoy reads are simulated from each decoy reference and then
re-mapped to all seven reference builds, measuring where they land and how
well they align.

**Prerequisites:** steps 01 (ART simulation) and 03 (alignment) must have
completed for both decoy panels (`hs37d5` and `hs38d1`).

---

## Directory structure

```
01_simulated_reads_alignment_location/   # Fig 2b — where do decoy reads map?
    01_get_idxstats.sh                   # run samtools idxstats on all BAMs
    02_parse_idxstats.py                 # parse idxstats → per-category CSVs
    03_plot.R                            # stacked bar plot → fig2b/

02_simulated_reads_alignment_quality/    # Fig 2c — how well do decoy reads map?
    01_get_coverage.sh                   # compute covered bases at 8 MAPQ thresholds
    02_plot.R                            # line plot → fig2c/
```

BED files are generated by `00_reference_genomes/03_make_bed.sh` and are
required by `01_get_coverage.sh`. To generate them run:

```bash
bash 00_reference_genomes/03_make_bed.sh
```

---

## Running the analysis

Run scripts from the repository root or from within the subdirectory — both
work because each script sources `config.sh` relative to its own location.

### Figure 2b — alignment location

```bash
bash 01_simulated_reads_alignment_location/01_get_idxstats.sh
python3 01_simulated_reads_alignment_location/02_parse_idxstats.py
Rscript 01_simulated_reads_alignment_location/03_plot.R
```

### Figure 2c — alignment quality

```bash
bash 02_simulated_reads_alignment_quality/01_get_coverage.sh
Rscript 02_simulated_reads_alignment_quality/02_plot.R
```

`01_get_coverage.sh` runs `samtools depth` at 8 MAPQ thresholds for every
reference × decoy combination and takes roughly 30–60 minutes on a single
core. Submit as a SLURM job if running on a cluster.

## Inputs and outputs

| Path (relative to repo root) | Description |
|---|---|
| `data/simulated/<decoy>/aligned/<ref>/<decoy>.bam` | Input BAMs from step 03 |
| `resources/bed_files/<ref>.bed` | Chromosome regions for coverage calculation |
| `results/intermediate/simulated_reads_alignment_location/` | idxstats files + parsed CSVs |
| `results/intermediate/simulated_reads_alignment_quality/` | Coverage files (one per ref × decoy) |
| `results/figures/fig2b/fig2b.{pdf,png}` | Figure 2b output |
| `results/figures/fig2c/fig2c.{pdf,png}` | Figure 2c output |

## Contig classification (Fig 2b)

`02_parse_idxstats.py` classifies every contig in the idxstats output into
four categories:

| Category | Contigs |
|---|---|
| Main chromosomes | chr1–22, X, Y, M (and non-prefixed 1–22, X, Y, M) |
| Decoy sequence | hs37d5, JTFH\*, KN\*, \*decoy, EBV accessions |
| Unplaced sequence | chrUn\_\*, GL\*, \*\_random, \*\_alt, HLA\* |
| Unmapped | unmapped read count column + `*` sentinel row |
